# Autism Detection Using AI & Machine Learning

## Overview

Autism Spectrum Disorder (ASD) is a developmental condition that affects communication, behavior, and social interaction. Early detection can significantly improve intervention outcomes.

This project presents an AI-based autism detection system that combines questionnaire-based screening and image classification techniques to assist in the identification of ASD indicators.

## Features

* Questionnaire-based autism screening
* Image-based autism classification
* Multiple machine learning models
* Automated prediction and assessment
* Interactive Python application

## Machine Learning Algorithms Used

* Logistic Regression
* Support Vector Classification (SVC)
* K-Nearest Neighbors (KNN)
* Naive Bayes

## Technology Stack

* Python
* Scikit-learn
* Pandas
* NumPy
* Jupyter Notebook
* Docker

## Project Workflow

1. Data Collection
2. Data Preprocessing
3. Feature Engineering
4. Model Training
5. Model Evaluation
6. Autism Prediction

## Results

The system evaluates behavioral responses and image-based inputs to provide autism risk assessment using machine learning classification models.
